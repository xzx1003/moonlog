# MoonLog browser workbench

Purpose: import one local log, locate error spikes, inspect original evidence, download JSON.

References: https://github.com/Studio-Groei/anti-slop and https://github.com/muris11/anti-ai-slop.
We apply their shared emphasis on purposeful hierarchy, specific copy and restraint.

Direction: an incident investigation workbench. Warm neutral canvas, paper report,
monospace counts and source lines, dark primary buttons, rust focus accents and amber evidence.
The supplied bento, button and accordion examples inform the warm palette, unequal
content blocks, 42px controls and plus/minus disclosures. Copy uses literal task
labels rather than slogans or English section decorations.
No decorative gradients, invented metrics, remote fonts or external assets.

The default view prioritizes file import. File selection, detection parameters and filters form a three-step flow.
Progress reflects the two actual file scans (0–50%, 50–100%), with completion
confirmed only when the report arrives. The bundled sample is synthetic, not a real production incident.
Results preserve the difference between filtered statistics and observed error ratio.
The browser currently supports one file, default JSON fields, and raw JSON export.
